# Enns Entomology Museum — media

Photos and other files used on the [Enns Entomology Museum website](https://enns-entomology-museum.github.io/Enns_Entomology_Museum_Database/),
kept here so the website's own repository stays small.

Everything in this repository is published with GitHub Pages at
`https://enns-entomology-museum.github.io/media/<folder>/<file>`.

## news/

Photos for the news posts written in TaxonWorks.

- Name: `YYYY-MM-short-title.jpg` (e.g. `2026-10-gbif-publisher.jpg`).
- Landscape, about 1600 px wide, JPEG, under ~300 KB.
- In the TaxonWorks news text, put the photo first so it becomes the story's cover:

      ![Caption](https://enns-entomology-museum.github.io/media/news/2026-10-gbif-publisher.jpg)

- A photo is online about a minute after it is pushed.

## Keeping it small

This repository can be cleaned up at any time without touching the website code.
If it ever grows too large, old photos can be moved to an archive (for example a
GitHub release or Zenodo) and the repository history squashed.
